# Sistema de Iconos Focus

Los iconos propios viven en `assets/focus_icons/` y deben sentirse como una misma familia: cuadrados redondeados, fondo vibrante, brillo suave y símbolo blanco/simple.

## Familia Actual

- `focus_focus.png`: identidad general / inicio.
- `focus_points.png`: puntos.
- `focus_streak.png`: racha.
- `focus_pomodoro.png`: pomodoro.
- `focus_subjects.png`: materias.
- `focus_exams.png`: exámenes.
- `focus_habits.png`: hábitos.
- `focus_friends.png`: amigos.
- `focus_resources.png`: recursos.
- `focus_achievements.png`: logros.
- `focus_ranking.png`: ranking.

## Uso

- Usa `FocusAppIcon` para mostrar el icono sin contenedor.
- Usa `FocusAssetBadge` para mostrarlo dentro de una tarjeta/chip visual.
- Usa `FocusMetricIcon` para puntos y racha.
- Material Icons quedan reservados para acciones: editar, eliminar, buscar, cerrar, abrir, ajustes.

## Reglas Visuales

- Azul: Focus, pomodoro, ranking e inicio.
- Teal/mint: materias, hábitos y progreso.
- Amber: puntos, exámenes, logros y recompensas.
- No mezclar emojis como icono principal.
- No usar iconos Material para métricas principales si ya existe PNG Focus.
